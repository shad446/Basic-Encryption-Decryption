# DecodeLabs – Project 2
## Basic Encryption & Decryption

**Internship:** DecodeLabs Cyber Security Internship – 2026

### Project Overview
This project implements a basic encryption and decryption system using the Caesar Cipher technique in Python.

### Objectives
- Encrypt user-provided text.
- Decrypt encrypted messages.
- Allow users to select a custom shift key.
- Display encryption and decryption results.

### Technologies Used
- Python
- Streamlit
- VS Code

### Project Files
- `main.py` – Terminal-based encryption and decryption.
- `app.py` – Streamlit graphical application.
- `requirements.txt` – Project dependencies.

### Encryption Technique
The Caesar Cipher shifts alphabetic characters by a specified number of positions.

### Features
- Interactive encryption and decryption.
- Custom shift key (1–25).
- Input validation.
- Preservation of spaces, numbers and punctuation.
- Graphical user interface.
### Preview Link https://basic-encryption-decryption-c4qpqepd2wcnkwqyxd4zkv.streamlit.app/
### Important Security Note
Caesar Cipher is an educational encryption technique and is not suitable for protecting sensitive information in real-world applications.

### Conclusion
This project demonstrates fundamental cryptographic concepts and practical Python programming skills through a working encryption and decryption application.
